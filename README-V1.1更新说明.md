# GPS测速仪 V1.1 更新说明

## 新增与优化
1. **暂停 / 继续测速**：暂停时停止 GPS 更新并保留当前记录；继续后重新获取定位。重新开始会清空本次记录。
2. **改善速度稳定性**：提高 GPS 更新频率；过滤精度差于 35 米的定位点；使用轻量平滑减少速度跳动；距离统计排除时间间隔过长或位置跳变过大的定位点。
3. **新增 App 图标**：加入速度表主题图标，支持新旧 Android 图标显示方式。
4. **性能优化**：速度表改用硬件加速绘制；曲线仅绘制最近 240 个点；测速数据保留上限为 3600 个点，避免长期运行时无限增长。
